# Criteria

## Interpretation
The objective is to build a Web Speech API tracer slice (slice.html) with CSS/SVG cutout animation, capabilities.md, and manifest.md. The headless browser verifies JS execution without errors and extracts frames for perceptual check.

## Claims
- C1: capabilities.md exists.
- C2: manifest.md exists and contains 'format' and 'sample'.
- C3: slice.html exists.
- C4: slice.html is valid HTML (has <html>).
- C5: slice.html uses window.speechSynthesis.
- C6: slice.html uses <svg and <style.
- C7: slice.html runs in a headless browser with no JS errors and generates frame screenshots.
- C8: Frames depict cutout animation (kit.perceive).
- C9: Subjective quality >= 7/10 against Goal Constitution (kit.judge).
