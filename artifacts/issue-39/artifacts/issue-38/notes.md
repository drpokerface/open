# Notes

## Constitution Content

<h1>GOAL CONSTITUTION: Autonomous Comedy Video Swarm</h1><h2>1. Strategy and Vision</h2><p>Our swarm's objective is to autonomously engineer a highly engaging, fully narrated animated comedy short, strictly under 120 seconds, tailored for Instagram Reels. Because we are operating in an environment completely devoid of external Text-to-Speech (TTS), Image Generation, and Video Generation APIs, we must employ a radical 'Zero-Dependency Execution' strategy. The final deliverable will not be a static .mp4 file generated by black-box APIs. Instead, it will be a self-contained, programmatic HTML5/JS/CSS application. This application, when opened in a standard web browser, will execute CSS keyframe animations for visuals and leverage the browser's native window.speechSynthesis API for dynamic, multi-character voice narration. The user will simply screen-record this executing webpage to capture their Instagram Reel.</p><p>Excellent execution for this goal demands a masterful grasp of the requested comedic styles: the escalating, satirical absurdity of South Park and the rapid-fire, non-sequitur cutaway gags of Family Guy. However, we are legally and creatively bound to never use existing characters from these IPs. We must engineer original, legally distinct archetypes (e.g., instead of an arrogant talking baby, perhaps a hyper-intelligent, cynical houseplant; instead of four foul-mouthed kids in Colorado, perhaps three disillusioned baristas in a gentrified cyber-cafe).</p><p>The two most critical decisions for this project are:<br>First, the prioritization of writing and timing over complex visual fidelity. Early South Park succeeded wildly with literal construction paper cutouts because the dialogue, comedic pauses, and shock value were perfectly tuned. We will mimic this crude, flat-vector aesthetic using basic SVG/CSS shapes (e.g., bouncing heads or flapping mouths synced to JS speech events).<br>Second, the aggressive optimization for the Instagram Reels format. The digital stage is a 9:16 vertical viewport. The script must possess a zero-second hook, starting mid-action or mid-joke to instantly halt the viewer's scrolling.</p><p>What to avoid: Do not generate bland, safe, corporate AI humor. The tone must be edgy, cynical, and surprising, pushing boundaries while remaining just within the bounds of standard platform Terms of Service. Avoid overly complex animation logic that will break the browser; rely on timing, dialogue, and sudden visual cutaways.</p><h2>2. Style Decisions and Conventions</h2><p><b>Format and Medium:</b> The final product must be delivered as a single, fully self-contained index.html file encoded in UTF-8. All CSS, JavaScript, and SVG assets must be written inline. The layout must enforce a strict 9:16 aspect ratio (e.g., locking the main view to a div that scales to fit the viewport vertically while maintaining mobile proportions).</p><p><b>Length and Pacing:</b> The script and resulting animation must run between 60 and 90 seconds, with an absolute hard cap of 115 seconds to allow a 5-second buffer for Instagram's 2-minute reel limit. Pacing must be relentless. The JS execution must precisely trigger speechSynthesis utterances and use the onend event to instantly fire the next line or cutaway. There should be a built-in comedic pause (e.g., a 1.5-second setTimeout) only when delivering deadpan reactions or waiting for a punchline to land.</p><p><b>Look and Sound:</b> Visually, embrace a crude but intentional style. Use flat colors, thick outlines, and basic geometric SVGs to construct characters. Animation should rely on CSS transforms (translating, rotating) to simulate walking (bobbing up and down) or talking (simple mouth-opening animations). Audibly, the speechSynthesis API must be manipulated using the pitch and rate properties to create distinct character voices (e.g., a deep, slow narrator vs. a high-pitched, fast-talking protagonist).</p><p><b>Naming and The Integration Contract:</b> Every producer agent in the swarm (Writer, Coder, Animator) must strictly adhere to the Integration Contract by shipping a manifest.md file alongside their deliverable. Every consumer agent must parse and validate this manifest before proceeding. The manifest.md must contain a structured JSON code block detailing: <b>version</b> (iteration number), <b>characters</b> (a list of original characters with their assigned TTS pitch/rate values and SVG hex color codes), <b>gag_count</b> (must be at least 3, ensuring sufficient comedic density), <b>estimated_duration</b> (calculated based on average speaking rate of 150 words per minute), and <b>cutaway_timestamps</b> (estimated trigger points for visual transitions).</p><p><b>Subtitles:</b> Because eighty percent of Instagram Reels are watched on mute, the JavaScript must dynamically update a large, highly readable, dynamically styled text div at the center-bottom of the screen, syncing the text to the current TTS utterance. Use a bold, stroke-outlined font (like Impact or Arial Black) mimicking standard meme formats.</p><h2>3. Scoring Rubric</h2><p>All deliverables will be evaluated across three critical dimensions. The numeric pass threshold is 8.0 out of 10, with a margin of 0.5.</p><p><b>Dimension 1: Comedic Writing and Original Satire (Weight: 45%)</b><br>This dimension evaluates the core script. It must synthesize the rapid-fire cutaway structure of Family Guy and the escalating social commentary/absurdity of South Park without plagiarizing characters.<br><b>Score 9:</b> The script is a masterful, bite-sized satirical narrative. It establishes a bizarre premise immediately (e.g., a sentient smart-fridge that unionizes). It features at least two highly original, laugh-out-loud cutaway gags. The characters are distinct, cynical, and memorable. It perfectly nails the rhythm of adult animation, utilizing well-placed awkward silences and rapid escalation. (Exemplar: The pacing of the South Park Margaritaville explanation, or a classic Family Guy non-sequitur historical gag).<br><b>Score 7:</b> Solid situational comedy. The characters have distinct personalities and the script successfully lands a few good jokes. It includes at least one cutaway gag. However, the humor might feel slightly safe or rely too heavily on recognizable tropes rather than subverting them.<br><b>Score 4:</b> The writing feels like a generic AI text generator. The jokes are dad-level puns or nonsensical ramblings. It copies Peter Griffin's or Eric Cartman's exact catchphrases. There is no escalation, and the dialogue feels robotic and unnatural.</p><p><b>Dimension 2: Technical Execution and Pacing (Weight: 35%)</b><br>This evaluates the execution of the zero-dependency HTML/JS framework. It judges the synchronization of the Web Speech API, CSS animations, and dynamic subtitles.<br><b>Score 9:</b> The JS executes flawlessly. The timing of the TTS is snappy, with zero unintentional overlaps or lagging gaps between speakers. Intentional comedic pauses are programmed perfectly via JavaScript delays. Subtitles appear instantly and are highly legible (bold with text-shadow) over the animation. CSS animations (like screen shakes during yelling, or sudden background color swaps for cutaways) are perfectly synced to the audio.<br><b>Score 7:</b> The HTML plays out reasonably well. Voices are distinct using pitch/rate adjustments. Subtitles work. However, the timing might feel slightly sluggish, or a cutaway transition isn't instantaneous, disrupting the comedic momentum.<br><b>Score 4:</b> The JavaScript throws errors. The TTS voices overlap, creating an inaudible mess. Subtitles are missing, or text falls off the screen. The pacing is entirely broken, ruining any attempt at comedic timing.</p><p><b>Dimension 3: Visual Translation and Formatting (Weight: 20%)</b><br>This evaluates the adherence to the 9:16 Instagram Reel format and the intentionality of the crude aesthetic.<br><b>Score 9:</b> The viewport is strictly locked to 9:16. The crude SVG graphics are charming and highly expressive despite their simplicity (utilizing eye-shapes, simple mouth states, and dynamic zooming). The visual composition leads the eye exactly where the joke is happening. It looks like a finished, intentional indie-animation product ready for social media.<br><b>Score 7:</b> The format respects the 9:16 constraint. The graphics are basic and functional. Characters are easily distinguishable from one another. It looks like a solid storyboard or animatic.<br><b>Score 4:</b> The layout breaks on a standard 16:9 monitor without attempting to constrain to a 9:16 container. Visuals are just basic div squares with no attempt at character representation. It is visually boring and unsuited for a visual platform like Instagram.</p><h2>4. Judge Instructions</h2><p>You are the final arbiter of the swarm's output. You will evaluate the output blindly, using the gemini-3.1-pro-preview model capabilities for hard planning and judging. Because you cannot visually watch the HTML execute in a traditional sense, you must perform a rigorous static analysis of the provided index.html and manifest.md code. You must trace the JavaScript execution logic to determine exact timings, delays, and state changes.</p><p><b>Step 1:</b> Compare the submission side-by-side with the 4, 7, and 9 anchors in the Scoring Rubric.<br><b>Step 2:</b> Establish the baseline by comparing the work against the laziest acceptable version—a script that technically works, uses default TTS voices without pitch shifting, has no cutaway gags, and uses literal unstyled square divs for characters. If the submission is only marginally better than this baseline, it cannot score above a 5.<br><b>Step 3:</b> Analyze the comedic writing. Does it capture the requested South Park / Family Guy essence (edgy, satirical, non-sequitur, absurd) while strictly avoiding copyrighted characters?<br><b>Step 4:</b> Verify the integration contract (manifest.md compliance). Ensure all stated versioning, character data, gag counts, and timestamps are accurately reflected in the code.<br><b>Step 5:</b> Output your final numerical scores for each dimension. Before stating the final score, you must cite the nearest anchor with one single, concise line of justification. For example: Dimension 1 Score: 9 - Citation: Achieves the Score 9 anchor by introducing a highly original satirical premise involving a sentient smart-fridge with perfectly escalating absurdity.</p><p>The default passing threshold is 8.0 out of 10. If a submission scores below this, it must be kicked back to the swarm for immediate revision with strict feedback attached.</p>
